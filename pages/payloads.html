Hardware & Platform

SkyMind Stack
覆盖飞行全链路的硬件与平台矩阵

围绕 SkyMind 飞控构建的硬件与平台矩阵，可按行业需求灵活组合， 支撑从单机到机队的全场景作业，覆盖飞行控制、感知、通信、能源与数据全链路。

控

Flight Control System

飞控系统

SkyMind FC-X 是翱越整机产品的核心控制中枢，采用双冗余 IMU 与 AI 协处理器架构， 毫秒级故障切换保障飞行安全，开放式 SDK 支持行业用户二次开发与系统集成。

双冗余 IMU 架构

双 IMU 与双指南针独立采样，主备链路实时比对，故障时毫秒级无缝切换。

AI 协处理器

8 TOPS 算力 AI 协处理器，支持实时目标识别、轨迹规划与边缘决策。

RTK 厘米级定位

多星座多频段 RTK 解算，提供厘米级定位精度，满足工业级作业要求。

开放式 SDK 与 API

提供完善的开发 SDK 与 API 文档，支持行业用户二次开发与生态集成。

主频800 MHz 双核
AI 算力8 TOPS
定位精度RTK 厘米级
通信接口CAN×4 / UART×6
工作温度-20°C 至 60°C
载

Pods & Payloads

吊舱与载荷

覆盖可见光、红外、多光谱与激光雷达的多模态载荷矩阵，通过统一接口与智能调度， 支持单机多载荷协同作业，灵活适配不同行业场景的感知需求。

可见光高分辨率相机

支持 4K 视频与高像素静态拍摄，满足巡检与测绘的高质量影像采集需求。

红外热成像

高灵敏度红外探测，支持温度异常识别与夜间作业，适用于电力与消防场景。

多光谱相机

多波段光谱数据采集，支撑农业长势评估、林业病害分析等植被监测场景。

机载激光雷达

高密度点云采集，免相控作业，直接输出高精度三维模型成果。

可见光4K / 2000 万像素
红外分辨率640×512
多光谱波段5 波段
LiDAR 点频240 kHz
载荷接口统一快拆
链

Data Link

图数链路

自研 OFDM 远距图数一体链路，单链路同时承载高清视频、遥控指令与遥测数据， 端到端 AES-256 加密，为 BVLOS 超视距作业提供稳定、安全、可靠的通信保障。

OFDM 调制与跳频

OFDM 调制结合自适应跳频，复杂电磁环境下保持稳定连接。

图数一体单链路

单链路同时传输 1080P 视频、遥控指令与遥测数据，简化系统部署。

AES-256 端到端加密

链路层 AES-256 全链路加密，保障飞行指令与数据传输安全。

双频自适应

2.4G / 5.8G 双频段自适应切换，避免频段拥堵与干扰。

通信距离≤ 30 km
视频分辨率1080P @ 60fps
链路延迟≤ 80 ms
加密方式AES-256
工作频段2.4G / 5.8G
站

Ground Station

地面站

便携三防与机柜指挥席多形态地面站，满足从单兵野外作业到多机协同指挥的全场景需求， 高亮屏与一体化操控设计保障复杂环境下的可靠操作。

高亮触控屏

1000 nits 高亮屏，户外阳光下清晰可见，支持手套与湿手触控。

三防结构设计

IP65 防护与 1.5 米跌落抗冲击，适应野外恶劣作业环境。

一体化操控

集成摇杆、按键与滚轮，单手即可完成主要飞行操作，简化作业流程。

多形态适配

便携式与机柜指挥席两种形态，覆盖单兵作业与多机协同指挥场景。

屏幕尺寸7 英寸
屏幕亮度1000 nits
防护等级IP65
跌落抗冲击1.5 m

能

Power & Energy

动力能源

高能量密度智能电池与混合动力系统，搭载电池健康管理与智能调度， 支撑长航时作业，并通过智能充电网络保障机队连续作业能力。

高能量密度电芯

采用高能量密度电芯，在保证安全性的前提下显著延长续航时间。

智能电池管理

混合动力系统

油电混合动力方案，兼顾大载重与长航时，满足 BVLOS 长距离作业需求。

智能充电网络

多通道智能充电柜与机库充电接口，支持机队连续作业与自动换电。

Data Platform

航线规划与任务编排
